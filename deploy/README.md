# Hosting LocalLead for $0

Cloudflare cannot run this backend for free: Pages/Workers serve static files and
edge functions, not a FastAPI + Postgres + Redis stack. Cloudflare Containers
(`cloudflare/`) runs the whole app on Cloudflare, but needs the $5/mo Workers
Paid plan.

This is the free split — **frontend on Cloudflare, API on Render**:

```
Browser ──▶ Cloudflare Pages (Next.js, free)  ──▶  Render free web service (FastAPI)
                                                     ├─ Neon        (Postgres, free)
                                                     └─ Upstash     (Redis, free)
```

## 1. Datastores (free)

| Service | What to copy |
|---|---|
| **Neon** (neon.tech) | connection string, then rewrite the scheme: `postgresql+psycopg2://USER:PASS@HOST/DB?sslmode=require` |
| **Upstash** (upstash.com) | Redis URL with TLS: `rediss://default:PASS@HOST:6379` |

Redis only carries live progress events; jobs run inside the API process.

## 2. API on Render (free)

Dashboard → **New → Blueprint** → select `Itsmekanishk/Lead_GEN_V3` (this
committed `deploy/render.yaml`). Or create a **Web Service** manually:

- Language **Docker**, Dockerfile path `deploy/render/Dockerfile`, context `.`
- Health check path `/api/health`
- Plan **Free** (512 MB RAM)

Then set these environment variables:

| Key | Value |
|---|---|
| `DATABASE_URL` | Neon URL above |
| `REDIS_URL` | Upstash URL above |
| `CORS_ORIGINS` | `https://<project>.pages.dev,https://yourdomain.com` |
| `FRONTEND_ORIGIN` | `https://<project>.pages.dev` |
| `SECRET_KEY` | generated by the blueprint, or `openssl rand -hex 32` |
| `BUSINESS_PROVIDER` | `nominatim` (keyless) or `google`/`serper`/`geoapify` + key |

The container runs `alembic upgrade head` on boot, so the schema is created on
the first deploy. Verify:

```bash
curl -s https://locallead-api.onrender.com/api/health
# {"status":"ok","checks":{"database":"ok","redis":"ok","workers":"no_workers","provider":"ok"}}
```

`workers: "no_workers"` is expected: without a Celery worker the API runs each
search in-process.

**Free-plan behaviour:** the service sleeps after 15 idle minutes and takes
~1 minute to wake, and anything still running stops when it sleeps. For a
demo that is acceptable; for always-on, use the Cloudflare Containers path.

## 3. Frontend on Cloudflare Pages (free)

Pages → **Create application → Pages → Connect to Git** → this repo.

| Setting | Value |
|---|---|
| Framework preset | None (or Next.js) |
| Root directory | `frontend` |
| Build command | `npx @cloudflare/next-on-pages@1` |
| Build output directory | `.vercel/output/static` |
| Runtime compatibility | flag `nodejs_compat`, date `2026-05-03` — already set in `frontend/wrangler.toml` |
| Environment variable | `NEXT_PUBLIC_API_URL=https://locallead-api.onrender.com` |

`nodejs_compat` is required, not optional: the generated `_worker.js` imports
`node:buffer` and `node:async_hooks`, and the Worker throws at runtime without
the flag. If the dashboard asks instead of reading `frontend/wrangler.toml`, set
it under **Settings → Functions → Compatibility flags**.

`NEXT_PUBLIC_API_URL` is inlined at build time, so the browser calls the Render
API directly (no rewrites — `next.config.mjs` disables them when that variable is
set). `results/[jobId]` declares `runtime = "edge"` because next-on-pages can
only serve it from the edge runtime.

After the first deploy, put the Pages URL into Render's `CORS_ORIGINS` and
`FRONTEND_ORIGIN`, then trigger a redeploy of the API.

### Deploy from the CLI instead

```bash
cd frontend
NEXT_PUBLIC_API_URL=https://locallead-api.onrender.com npx @cloudflare/next-on-pages@1
npx wrangler pages deploy .vercel/output/static --project-name locallead
```

## 4. Custom domain

- Pages → your project → **Custom domains → Set up a domain**.
- Add that domain to Render's `CORS_ORIGINS` / `FRONTEND_ORIGIN`.

## Alternatives

| Option | Cost | Trade-off |
|---|---|---|
| **This split** | $0 | API cold-starts, 512 MB |
| `cloudflare/` Containers | $5/mo | Everything on Cloudflare, no app changes, 4 GB RAM |
| Oracle Cloud / Hostinger VPS + Cloudflare DNS | $0–5/mo | Always-on; see `docs/HOSTINGER_DEPLOYMENT.md` |
